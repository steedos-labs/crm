# 用户手册

> W6 完成后填充。本文档面向终端用户（销售员、销售主管、市场专员、客服、管理员）。

## 1. 章节规划

| 章节 | 内容 | 负责角色 |
|---|---|---|
| 1. 登录与基础导航 | 账号、Tab、搜索 | 全员 |
| 2. 销售流程 | 线索→客户→商机→报价→合同 | sales_rep / sales_manager |
| 3. 市场营销 | 创建活动、批量加入成员、查看 ROI | marketer |
| 4. 客户服务 | 工单创建、SLA 监控、知识库 | service_agent |
| 5. 数据分析 | Dashboard 解读、自定义 question | sales_manager / admin |
| 6. 系统管理 | 用户、角色、权限、数据导入 | admin |
| 7. 常见问题 | FAQ | 全员 |

## 2. 编写规则

- 每章 ≤ 800 字 + 截图。
- 截图统一在浏览器宽 1440 px 下采集。
- 引用元数据 API name 时加反引号；引用 UI 文案使用「中文引号」。
- 与 [business-flows/](../business-flows/) 文档一一对应，禁止编造功能。
