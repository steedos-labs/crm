# 用户故事与用例

格式：`作为 <角色>，我希望 <能力>，以便 <价值>`。优先级：P0 必须、P1 应该、P2 可选。

## 1. 销售模块

| ID | 故事 | 优先级 | Sprint |
|---|---|---|---|
| US-S01 | 作为销售员，我希望批量导入线索，以便快速录入展会名单 | P1 | W2 |
| US-S02 | 作为销售员，我希望将合格线索一键转换为客户/联系人/商机，以便减少重复录入 | P0 | W2 |
| US-S03 | 作为销售员，我希望看到自己的商机看板（按阶段分列），以便聚焦推进 | P0 | W2 |
| US-S04 | 作为销售主管，我希望查看团队销售漏斗，以便预测季度业绩 | P0 | W5 |
| US-S05 | 作为销售员，我希望基于商机生成报价单，以便发送给客户 | P1 | W2 |
| US-S06 | 作为销售员，我希望记录每次电话/会议，以便回顾跟进过程 | P0 | W2 |

## 2. 营销模块

| ID | 故事 | 优先级 | Sprint |
|---|---|---|---|
| US-M01 | 作为市场，我希望创建营销活动并设置预算，以便统一管理 | P0 | W3 |
| US-M02 | 作为市场，我希望批量将一批线索/联系人加入活动，以便跟进效果 | P0 | W3 |
| US-M03 | 作为市场，我希望在活动详情看到成员状态分布与 ROI，以便评估效果 | P0 | W3 |
| US-M04 | 作为市场，我希望维护邮件模板，以便给销售复用 | P1 | W3 |
