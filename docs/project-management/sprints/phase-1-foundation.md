# 第一阶段：基础工程和主数据

## 阶段目标

建立 Steedos CRM 项目的基础工程、CRM 包、应用导航、基础权限集和客户主数据对象，为后续销售流程、报价合同和服务分析打基础。

## 任务列表

| 编号 | 任务 | 状态 | 验收要点 |
| --- | --- | --- | --- |
| CRM-001 | 初始化 Steedos 基础项目结构 | 待验收 | `package.json`、`steedos-config.yml`、`.gitignore`、基础环境说明齐全 |
| CRM-002 | 创建 CRM Steedos 包 | 待验收 | `steedos-packages/crm` 包结构齐全 |
| CRM-003 | 创建 CRM 应用和导航框架 | 待验收 | 应用、侧边栏分组、页签框架齐全 |
| CRM-004 | 创建基础权限集 | 待验收 | 销售经理、销售人员、服务人员、财务人员权限集齐全 |
| CRM-005 | 实现 `crm_accounts` 客户对象 | 待验收 | 对象、字段、权限、列表视图、页签齐全 |
| CRM-006 | 实现 `crm_contacts` 联系人对象 | 待验收 | 联系人对象关联客户，权限和列表视图齐全 |
| CRM-007 | 实现 `crm_leads` 线索对象 | 待验收 | 线索对象包含来源、状态和转化引用字段 |

## 交付范围

- Steedos 项目基础文件。
- `steedos-packages/crm` 包。
- CRM 主应用和基础导航。
- CRM 角色权限集。
- 客户、联系人、线索三个主数据对象。

## 不在本阶段范围

- 商机、报价、合同、发票和客户服务对象。
- 复杂自动化、仪表盘和报表。
- 外部系统集成。

## 阶段验收

- [ ] CRM 应用可以显示。
- [ ] 客户、联系人、线索可以从 CRM 应用侧边栏访问。
- [ ] 所有自定义对象均以 `crm_` 开头。
- [ ] 每个对象都有字段、权限和列表视图。
- [ ] 所有界面标签和文档均为中文。
- [ ] 已根据项目当前能力完成安装、启动或构建验证。
