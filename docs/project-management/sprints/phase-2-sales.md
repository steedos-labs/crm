# 第二阶段：销售过程

## 阶段目标

实现从线索到商机的销售过程管理，包括商机、商机产品、销售活动、销售任务和线索转化能力。

## 任务列表

| 编号 | 任务 | 状态 | 验收要点 |
| --- | --- | --- | --- |
| CRM-008 | 实现 `crm_opportunities` 商机对象 | 待开始 | 关联客户和联系人，包含阶段、金额、概率和预计成交日期 |
| CRM-009 | 实现 `crm_opportunity_products` 商机产品对象 | 待开始 | 与商机建立 master-detail 关系，支持产品、数量、单价和金额 |
| CRM-010 | 实现 `crm_activities` 销售活动对象 | 待开始 | 支持拜访、电话、会议、邮件等活动类型 |
| CRM-011 | 实现 `crm_tasks` 销售任务对象 | 待开始 | 支持负责人、到期日期、状态和我的任务视图 |
| CRM-012 | 实现线索转化能力 | 待开始 | 线索可转为客户、联系人和商机，并回写转化引用 |

## 交付范围

- 商机销售阶段管理。
- 商机产品明细。
- 销售活动和销售任务。
- 线索转化按钮、function 或等效实现。

## 不在本阶段范围

- 报价、合同和发票。
- 复杂销售预测报表。
- 客户服务流程。

## 阶段验收

- [ ] 线索可以进入销售跟进流程。
- [ ] 商机可以关联客户、联系人和产品明细。
- [ ] 销售任务和活动可以记录到客户或商机。
- [ ] 线索转化后保留原始线索和转化对象引用。
- [ ] 所有新增对象均以 `crm_` 开头。
- [ ] 所有新增对象均有权限、列表视图和导航入口。
