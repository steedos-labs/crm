# 第三阶段：报价合同

## 阶段目标

实现产品、价格、报价、合同、发票和回款相关能力，形成从商机到收入确认的业务链路。

## 任务列表

| 编号 | 任务 | 状态 | 验收要点 |
| --- | --- | --- | --- |
| CRM-013 | 实现 `crm_products` 产品对象 | 待开始 | 产品编码、分类、单位、标准价和状态字段齐全 |
| CRM-014 | 实现 `crm_price_books` 价格表对象 | 待开始 | 支持价格表基础信息、权限和列表视图 |
| CRM-015 | 实现 `crm_quotes` 报价对象 | 待开始 | 关联商机和客户，支持报价状态、总额和有效期 |
| CRM-016 | 实现 `crm_quote_items` 报价明细对象 | 待开始 | 与报价建立 master-detail 关系，支持产品、数量、单价和金额 |
| CRM-017 | 实现 `crm_contracts` 合同对象 | 待开始 | 关联客户、商机和报价，支持金额、日期和状态 |
| CRM-018 | 实现 `crm_invoices` 发票对象 | 待开始 | 关联合同和客户，支持开票金额、已收金额和回款状态 |

## 交付范围

- 产品和价格表基础管理。
- 报价和报价明细。
- 合同和发票。
- 报价生成合同、合同开票相关能力的基础设计或实现。

## 不在本阶段范围

- 复杂审批流。
- 与财务系统或电子签系统集成。
- 复杂税务规则。

## 阶段验收

- [ ] 产品可以被商机产品和报价明细引用。
- [ ] 报价可以关联商机和客户。
- [ ] 报价明细可汇总形成报价总额。
- [ ] 合同可以关联报价、商机和客户。
- [ ] 发票可以关联合同并维护回款状态。
- [ ] 财务人员权限与销售人员权限区分明确。
