# 第四阶段：服务和分析

## 阶段目标

实现客户服务记录、CRM 首页、销售仪表盘、基础数据初始化和关键自动化校验，提升系统可用性和管理可视化能力。

## 任务列表

| 编号 | 任务 | 状态 | 验收要点 |
| --- | --- | --- | --- |
| CRM-019 | 实现 `crm_service_cases` 客户服务记录对象 | 待开始 | 支持客户、联系人、类型、优先级、状态、主题和解决方案 |
| CRM-020 | 实现 CRM 首页 | 待开始 | 展示待办、待跟进线索、本月商机、服务问题和销售漏斗摘要 |
| CRM-021 | 实现销售仪表盘 | 待开始 | 展示商机阶段、负责人业绩、合同金额、开票回款和服务状态统计 |
| CRM-022 | 补充基础种子数据 | 待开始 | 线索来源、销售阶段、客户级别、产品分类和服务类型等数据齐全 |

## 交付范围

- 客户服务记录对象。
- CRM 首页微页面。
- 销售仪表盘或报表设计。
- 基础配置数据。
- 关键自动化校验。

## 不在本阶段范围

- 客户门户。
- 在线客服系统集成。
- 外部 BI 系统集成。

## 阶段验收

- [ ] 服务人员可以创建和处理客户服务记录。
- [ ] 服务记录可以关联客户和联系人。
- [ ] CRM 首页可以辅助销售人员处理日常工作。
- [ ] 销售仪表盘可以展示关键经营指标。
- [ ] 基础种子数据可用于下拉选项或初始化配置。
- [ ] 服务关闭时必须填写解决方案的规则已设计或实现。
